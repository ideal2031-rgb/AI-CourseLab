# Case 002 Template

第二个真实案例应验证与 CASE-001 不同的业务类型。推荐使用“芊小仙紫砂/非遗产业出海”资料，检验产业资源、产品、供应链、跨境经营和高校转化的组合识别。

## Required files

- manifest.json
- conversation_memory.md
- people_memory.md
- insight_memory.md
- opportunity_memory.md
- case_card.md

将 `status` 从 `template` 改为 `draft` 或 `validated` 后，必须补齐全部文件并运行校验。
