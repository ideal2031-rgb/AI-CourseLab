# Opportunity Memory

## OPP-001 小红书生态服务商联合项目

- rating：A-
- stage：discovery
- evidence：双方明确讨论平台资源、商家筛选、服务商资质、网红猫团队和案例组合。
- resource_fit：紫堇老师侧负责入口、诊断与资源协调；网红猫负责运营交付和案例。
- value_model：联合诊断、陪跑/托管、投放、达人和活动服务。
- prerequisites：案例授权、服务包标准化、客户准入、签约和分润机制。
- risks：平台政策变化、跨平台利益冲突、交付责任不清。
- next_action：制作联合合作一页纸和尽调清单，完成一次正式商务会谈。
- evidence_level：confirmed + inferred。

## OPP-002 高校售前客服生产性实训 MVP

- rating：B+
- stage：signal
- evidence：网红猫明确认为售前客服是较适配的可外放模块，并认可杭州本地高校方向。
- value_model：真实客服任务、人才筛选、企业导师和课程实训。
- prerequisites：产品知识库、账号权限、排班、SLA、质检、数据安全和企业督导机制。
- risks：学生响应质量、平台账号安全、企业督导成本高于收益。
- stop_conditions：无法获得脱敏沙箱或企业无法提供稳定督导时暂停。
- next_action：选择单品牌、单平台、20 人以内、2 周的沙箱测试。
- evidence_level：confirmed + inferred。

## OPP-003 时尚品牌跨境标杆试点

- rating：B
- stage：signal
- evidence：网红猫存在国内成熟品牌资源和跨境意愿，但尚无成熟案例。
- value_model：出海诊断、平台冷启、内容与达人测试、陪跑服务费。
- prerequisites：确定种子品牌、目标国、平台、预算和授权。
- risks：供应链、合规、物流、库存及平台能力不足。
- next_action：筛选一个已有海外仓或明确赴美计划的品牌进行可行性诊断。
- evidence_level：confirmed + hypothesis。
