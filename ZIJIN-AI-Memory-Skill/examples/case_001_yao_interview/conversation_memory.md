# Conversation Memory

## Context

紫堇老师与网红猫负责人及 MCN 业务负责人围绕小红书生态服务商、高校生产性实训、多平台代运营和跨境业务进行合作沟通。

## Confirmed facts

- 网红猫聚焦女装、女鞋及大服饰，拥有 20+ 合作品牌；访谈材料称上一年度整体销售额 5 亿元以上，天猫约占 60%，其中 3 个品牌年销过亿元。
- 网红猫已设小红书/抖音相关 MCN 团队，覆盖账号运营、种草、达人直播和投放。
- 全平台托管的访谈口径为每月固定服务费加销售佣金；具体报价属于商业信息，不作为公开推广承诺。
- 高校合作中，网红猫认为售前客服比内容批量生产更适合作为第一阶段生产性实训模块。
- 双方讨论了平台资源与服务交付能力组合，以及先做标杆案例再扩展跨境业务的原则。

## Core topics

1. 高校生产性实训：适合模块、企业督导成本和人才储备价值。
2. 小红书生态合作：官方资源、商家筛选、服务商申报与网红猫交付能力。
3. 品牌运营结构：货架经营、种草、达人直播和投放之间的组合。
4. 跨境试点：以成熟国内品牌和单一标杆案例验证，不做重资产自营。

## Agreements

- 高校实训先从标准化程度较高的售前客服模块继续评估。
- 网红猫需整理可公开的团队介绍、服务包、案例和资质材料。
- 紫堇老师侧负责进一步梳理生态服务商合作提案及平台资源对接。

## Open questions

- 联合业务的签约主体、客户归属、交付责任与收益分配。
- 高校客服实训的 SLA、知识库、督导投入和数据合规。
- 平台服务商政策和相关资格需以最新官方规则再次核验。
- 跨境标杆品牌、目标市场、预算和验收指标尚未确定。

## Excluded content

平台上市、人事变动等未经核验的闲聊不进入案例事实库。
