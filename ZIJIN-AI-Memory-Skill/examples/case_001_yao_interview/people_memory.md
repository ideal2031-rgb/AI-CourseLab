# People Memory

## People and organizations

### 姚总 / 网红猫

- 身份：多平台电商服务企业负责人。
- 已确认能力：时尚品牌代运营、货架经营、达人与种草资源、投放与团队管理。
- 主要约束：人力成本高、低质量客户消耗交付资源、跨境业务缺少成熟标杆案例。

### 杰瑞 / MCN 业务团队

- 身份：小红书及达人业务的实施负责人之一。
- 价值：可补充具体服务流程、产能、案例与报价信息。

### 紫堇老师 / 如歌侧

- 角色：平台培训与商家诊断入口、高校项目资源和合作方案组织方。
- 价值：前端筛选、平台关系、高校项目转化与方法论资产化。

## Relationship classification

- `partner`：双方拟共同组合前端资源与后端交付。
- `channel`：紫堇老师侧可提供平台/高校入口，网红猫侧也可提供品牌客户和产业资源。
- `project_owner`：网红猫掌握服务团队、品牌案例与具体交付能力。

姚总不是本案例中的“小红书代运营潜在客户”。把其归类为客户会误读合作结构。

## Inferences requiring verification

- 是否适合长期绑定为独家或优先交付伙伴，需要通过首个联合项目验证。
- 团队产能、案例使用授权和服务毛利需在商务尽调中核实。
