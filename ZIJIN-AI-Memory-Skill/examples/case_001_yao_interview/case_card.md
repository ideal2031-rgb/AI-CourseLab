# Case Card：网红猫合作访谈

## Metadata

- 日期：2026-07-27
- 类型：企业合作访谈
- 主题：小红书生态服务商、高校实训、跨境标杆
- 状态：validated

## Relationship map

紫堇老师/如歌侧提供平台与高校入口、诊断和方案组织；网红猫提供品牌经营、运营团队、达人种草和案例交付。双方关系以 partner + channel + project_owner 为主，而非客户与乙方关系。

## Situation and verified facts

网红猫是具备多平台时尚品牌运营基础的成熟服务商，正在寻找小红书生态增量、高校人才与任务协同以及跨境样板机会。紫堇老师侧需要稳定的后端交付伙伴，以承接平台和高校资源产生的真实项目。

## Key insights

1. 平台资源与代运营能力需要通过统一准入和联合产品连接。
2. 高校实训必须把企业督导和质检成本纳入模型。
3. 服务商案例应从“GMV故事”升级为“健康经营结构”。
4. 跨境应以单点 MVP 建立第一案例。

## Opportunity portfolio

- A-：小红书生态服务商联合项目。
- B+：高校售前客服生产性实训 MVP。
- B：时尚品牌跨境标杆试点。

## Risks and unresolved questions

- 合作主体、客户归属、收益分配和质量责任未确定。
- 案例授权、平台规则和服务资质需核验。
- 高校实训的数据安全与企业督导成本需先沙箱测试。

## Next actions

1. 网红猫提供脱敏服务包、团队资质、案例授权状态和标准报价。
2. 如歌侧形成联合合作一页纸、客户准入表和项目边界清单。
3. 单独立项验证高校客服 MVP，不与服务商申报捆绑。

## Reusable assets

- 服务商合作尽调清单
- 高校真实任务准入表
- 联合服务产品结构
- 跨境标杆项目 MVP 规则
