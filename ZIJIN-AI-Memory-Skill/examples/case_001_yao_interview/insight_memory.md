# Insight Memory

## 1. 前端资源必须与后端交付形成联合系统

- trigger：紫堇老师侧拥有平台、培训、诊断和高校入口；网红猫拥有运营团队、案例和品牌资源。
- judgement：单纯互相转介绍价值有限，更有效的模式是统一准入、联合方案、明确边界和交付分工。
- significance：可将一次性资源交换转化为持续业务闭环。
- boundary：必须先解决签约主体、客户归属、质量责任和收益分配。
- evidence_level：inferred。

## 2. 生产性实训不能只计算学生人力成本

- trigger：企业提出派驻运营经理可能抵消学生人力的成本优势。
- judgement：高校实训的真实成本包括任务设计、督导、质检、系统权限和返工管理。
- significance：决定企业是否愿意长期开放真实任务。
- applications：高校实训项目准入模型、企业任务书和 SLA。
- evidence_level：confirmed + inferred。

## 3. 服务商案例应优先证明健康经营结构

- trigger：访谈强调货架经营为主、达人直播占比较低，以及高成本自播可能导致双输。
- judgement：案例不应只展示单次 GMV，而应呈现货架、内容、投放、达人和利润之间的结构。
- boundary：具体经营数据需取得案例品牌授权。
- evidence_level：confirmed。

## 4. 跨境新业务先做单点样板

- trigger：网红猫明确要求先形成成熟标杆，再规模化推广。
- judgement：首个跨境项目应限定品牌、市场、平台、预算和周期，避免“大而全”试错。
- evidence_level：confirmed。
