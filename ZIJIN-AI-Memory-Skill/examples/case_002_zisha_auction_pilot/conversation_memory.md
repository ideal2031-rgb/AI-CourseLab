# Conversation Memory

## Context

紫堇老师与一名宜兴直播拍卖从业者讨论 TikTok Shop 美国市场的直播拍卖试点。后续又形成了项目合作方案和意向协议草案，用于把初步兴趣转化为分阶段验证项目。

## Confirmed facts

- 对方明确表达了开展跨境直播拍卖的意愿，并愿意准备主体、履历、国内业务和意向货盘材料。
- 对方称自己具备拍卖师身份和国内直播拍卖经验；相关证书、账号归属和业务数据仍需正式核验。
- 对方拥有或可连接紫砂、瓷器、玉石等产业资源，但具体商品权属、工艺师合作、品牌授权和库存尚未形成完整证据包。
- 对方希望海外业务使用独立主体，不直接依附于现有第三方合作机构。
- 项目方案将首案定位为 60—90 天验证型试点，而非直接进入重投入长期代运营。

## Core topics

1. 入驻主体、平台资格和拍卖功能路径。
2. 国内经营经历如何转化为申请与信用材料。
3. 首批货盘的品类、价格、来源、真实性和物流适配。
4. 真人直播、文化内容、AI 辅助和跨语言表达。
5. 交易、履约、售后、数据与案例授权。
6. 国际直播拍卖师职业模型及后续课程、研究和高校实训转化。

## Agreements

- 先完成资料、主体和货盘核验，再决定是否正式申请和投入。
- 首案应设置决策门，任何主体、商品或履约风险未解决时不得继续放量。
- 第三方拍卖机构、工艺师、工坊和历史经营数据必须取得授权并准确描述关系。
- 项目成果可沉淀为案例、SOP 和职业模型，但公开范围需书面审批。

## Open questions

- 实际签约主体与拟入驻主体是否一致、有效并适合跨境结算。
- 拍卖师证书、国内直播账号、成交数据和团队履历能否独立核验。
- 首批商品的权属、作者/品牌授权、材质、真实性、库存和交期。
- 美国市场的准确类目、拍卖功能资格、结算、物流、保险和退货路径。
- 项目费用、成果节点、佣金口径和平台激励归属。

## Excluded content

未核验的平台“绿通”“保过”或账户价格上限等口头信息，不作为本案例的确定事实。
