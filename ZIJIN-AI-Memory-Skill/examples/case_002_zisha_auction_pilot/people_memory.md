# People Memory

## People and organizations

### 芊小仙团队（公开脱敏称谓）

- 角色：直播拍卖从业团队、潜在跨境项目商家、货盘与履约资源组织方。
- 已确认诉求：建立独立海外业务抓手，测试美国市场，形成个人及团队的长期事业资产。
- 声称能力：拍卖师身份、国内直播拍卖经验、紫砂及其他工艺收藏品资源。
- 主要约束：主体、资质、账号数据、第三方合作关系、商品授权和跨境履约仍需核验。

### 紫堇老师 / 项目策划方

- 角色：准入研究、项目设计、内容与直播方法、AI 工作流、课程及案例研究组织方。
- 价值：把商家试点转化为分阶段项目、风险门、数据模型、SOP 和职业能力案例。
- 边界：不应承诺平台审核、功能开通、流量、成交或利润结果。

### 第三方机构、工艺师和工坊

- 角色：潜在履历证明、商品、作者和供应链资源。
- 当前状态：仅为资料线索或待授权合作关系。
- 公开规则：未取得书面证明前，不作为关联机构、官方背书或稳定供应链宣传。

## Relationship classification

- `prospective_client`：对方对准入诊断、申请策划、内容和试运营陪跑存在潜在采购需求，但尚未完成正式签约。
- `partner`：首案强调共同验证、数据共建和案例共创，不是纯粹购买标准服务。
- `project_owner`：对方掌握或组织主体、主播、货盘、库存、定价和履约，是经营责任主体。

## Relationship value

该关系适合作为跨境直播拍卖首案，但价值取决于对方是否能按期提交真实资料、承担商品与履约责任并接受阶段付费与风险边界。

## Inferences requiring verification

- 对方是否具备持续组织高质量货盘和专职团队的能力。
- 现有第三方合作经历能否合法用于新主体入驻材料。
- 对方是否愿意投入试点预算、提供后台数据并完成案例授权。
