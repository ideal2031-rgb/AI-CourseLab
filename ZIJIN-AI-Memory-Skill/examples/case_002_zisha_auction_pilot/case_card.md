# Case Card：宜兴紫砂跨境直播拍卖验证项目

## Metadata

- 日期：2026-07-13
- 类型：访谈 + 项目方案 + 意向协议
- 主题：跨境直播拍卖、非遗出海、职业模型、案例共创
- 状态：draft

## Relationship map

芊小仙团队同时具有 prospective_client、partner 和 project_owner 三种关系：可能采购项目服务；需要与紫堇老师团队共同验证新模式；并负责主体、商品、直播和履约。第三方拍卖机构、工艺师及工坊只作为待核验资源线索。

## Situation and verified facts

对方对美国市场直播拍卖有明确兴趣，并愿意准备申请材料和意向货盘。双方已将对话推进为 60—90 天验证型项目框架，目标覆盖准入、商品、内容、交易、履约、复盘和案例化，而不是只追求店铺开通或单场 GMV。

## Key insights

1. 高价值跨境项目先验证主体、货权和履约责任链。
2. 国内第三方合作履历必须授权并准确描述，不能直接迁移为新主体业绩。
3. “一品一档”是工艺品合规、内容和交易信任的共同底座。
4. 国际直播拍卖师可作为职业升级方向，但必须由真实经营证据支撑。
5. 高校实训应在市场 MVP 跑通后再转化。

## Opportunity portfolio

- B+：跨境直播拍卖 60—90 天 MVP。
- B+：国际直播拍卖师职业样板。
- B：东方美学商品内容知识库。
- C+：高校生产性实训任务包。

## Risks and unresolved questions

- 主体、资质、账号和历史经营数据尚未完成正式尽调。
- 第三方品牌、工艺师、工坊和商品授权状态不清。
- 平台拍卖资格、类目、物流、保险、退货和拒付路径需按最新规则核验。
- 项目费用、佣金、数据权限和案例授权尚未签署。

## Next actions

1. 乙方提交主体、资质、国内经营、合作证明、商品和履约资料。
2. 甲方输出准入诊断和 Go / Conditional Go / No-Go 结论。
3. Conditional Go 后再筛选首批商品，并建立内部一品一档。
4. 签署合作、保密、数据与案例授权文件后进入申请和内容准备。
