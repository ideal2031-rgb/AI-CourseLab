# Insight Memory

## 1. 跨境直播拍卖首案必须先验证责任链，而不是先做流量

- trigger：项目同时涉及主体、拍卖功能、商品真实性、跨境物流、退款拒付和第三方授权。
- judgement：任何内容和投放动作之前，必须明确谁是店铺、商品、交易、收款和消费者责任主体。
- significance：高价值工艺品的单次风险可能超过前期流量收益。
- applications：项目准入表、合同、Gate A-D、风险检查表。
- evidence_level：confirmed + inferred。

## 2. 国内成功经历不能直接等同于海外可用资质

- trigger：对方计划使用国内第三方合作经历支持新海外主体申请。
- judgement：可用的是经过授权、准确表述的个人履历和项目证明，不能混同第三方企业的整体业绩、商标或账号数据。
- significance：决定申请材料、案例宣传和知识产权风险。
- evidence_level：confirmed。

## 3. 中国工艺品出海需要“一品一档”的信任基础设施

- trigger：紫砂、瓷器、玉石等商品依赖作者、材料、工艺、来源、证书、瑕疵和故事说明。
- judgement：商品数据库既是合规工具，也是跨文化内容和高客单转化工具。
- applications：SKU 档案、双语拍品卡、内容知识库、客服问答库和高校任务包。
- evidence_level：inferred。

## 4. 国际直播拍卖师是可验证的职业升级方向

- trigger：项目同时要求拍卖专业、直播内容、AI、跨文化表达、平台经营和履约协同。
- judgement：职业价值不只在主持竞价，而在连接专业信用、内容、数据、供应链和国际市场。
- boundary：需要真实成交和履约数据后，才能形成稳定能力标准。
- evidence_level：inferred + hypothesis。

## 5. 高校转化应晚于市场 MVP

- trigger：本项目未来可形成课程、SOP 和学生任务，但当前仍处于准入与商业验证阶段。
- judgement：不能先把未经验证的经营假设包装成生产性实训；应先完成最小交易与履约闭环，再拆分为教学任务。
- evidence_level：inferred。
