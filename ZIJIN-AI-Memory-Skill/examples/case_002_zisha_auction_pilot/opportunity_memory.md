# Opportunity Memory

## OPP-201 跨境直播拍卖 60—90 天 MVP

- rating：B+
- stage：discovery
- evidence：对方有明确意愿、国内经验主张和产业货盘线索，项目方案已形成阶段与决策门。
- resource_fit：紫堇老师侧提供诊断、项目设计、内容与直播方法；对方提供主体、主播、商品、预算和履约。
- value_model：准入诊断费、申请与货盘交付费、试运营陪跑费、经书面确认的净支付 GMV 佣金。
- prerequisites：主体、资质、账号数据、第三方授权、首批商品和履约方案核验。
- risks：平台资格变化、商品真实性、知识产权、跨境破损、退货拒付和高价值库存。
- stop_conditions：无法提供合法主体、货权或可执行履约闭环时停止。
- next_action：完成资料尽调，形成 Go / Conditional Go / No-Go 诊断。
- evidence_level：confirmed + inferred。

## OPP-202 国际直播拍卖师职业样板

- rating：B+
- stage：signal
- evidence：首案具备持证拍卖师、直播业务和工艺品跨境的交叉场景。
- value_model：职业能力模型、课程、认证培训、行业研究和师资项目。
- prerequisites：至少形成真实准入、内容、交易、履约和复盘数据。
- risks：先做概念、后补证据；职业名称与认证边界不清。
- next_action：在项目数据结构中同步记录岗位任务和能力证据，但暂不对外宣称成熟标准。
- evidence_level：inferred。

## OPP-203 东方美学商品内容知识库

- rating：B
- stage：signal
- evidence：商品需建立作者、工艺、材料、来源、证书、故事与双语表达。
- value_model：内容生产、跨境客服、商品页、直播脚本、研究数据库和品牌资产。
- prerequisites：逐 SKU 核验和工艺师/工坊授权。
- risks：错误头衔、虚假来源、未经授权素材和文化表达失真。
- next_action：先建立首批 SKU 的内部档案，不公开未核验信息。
- evidence_level：confirmed + inferred。

## OPP-204 高校生产性实训任务包

- rating：C+
- stage：signal
- evidence：项目可拆为资料治理、双语商品卡、内容脚本、客服知识库和数据复盘任务。
- value_model：产业案例转课程、学生项目和非遗数字商业实训。
- prerequisites：市场 MVP 至少完成真实交易与履约，企业提供脱敏数据和稳定导师。
- risks：未经验证就教学化、学生接触敏感数据、高价值商品责任不清。
- stop_conditions：市场闭环未跑通前不进入生产性实训。
- next_action：只建立教学映射草案，待 MVP 结项后正式转化。
- evidence_level：hypothesis。
