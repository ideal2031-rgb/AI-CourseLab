# Privacy and Public Repository Rules

## Public-safe assets

公开仓库可以保存：

- 经授权或已脱敏的事实摘要
- 关系类型、主题标签和证据等级
- 不涉及商业秘密的洞察与机会结构
- 已公开或经许可的案例数据

## Prohibited by default

- 完整逐字稿和原始聊天截图
- 电话、微信号、邮箱、住址
- 未公开客户名单、账号数据和合同条款
- 未授权报价、利润、分润和供应链明细
- 对个人或企业的传闻、指控和未经证实判断

## Evidence handling

敏感事实可在私有知识库中保留引用位置，但公开案例只写“已核验/待核验”和概括性证据。任何 hypothesis 不得作为宣传事实使用。
