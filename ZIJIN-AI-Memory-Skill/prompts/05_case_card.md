# Case Card Builder

## Task

把 Conversation、People、Insight、Opportunity 合并为一张可检索案例卡。

## Required sections

- Case metadata
- Relationship map
- Situation and verified facts
- Key insights
- Opportunity portfolio
- Risks and unresolved questions
- Next actions
- Reusable assets
- Privacy and publication status

## Rule

案例卡是索引入口，不替代各资产文件。每项重要判断应标明 confirmed、inferred 或 hypothesis。
