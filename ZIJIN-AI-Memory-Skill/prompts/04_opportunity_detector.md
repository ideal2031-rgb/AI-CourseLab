# Opportunity Detector

## Task

识别真实合作机会，区分机会、想法和远期方向。

## Each opportunity includes

- 名称与类型
- 对应人物/组织
- 当前阶段：signal / discovery / qualified / proposal / negotiation / delivery
- 证据信号
- 双方资源组合
- 价值与潜在商业模式
- 前置条件
- 风险和停止条件
- 下一步动作、负责人和建议期限
- evidence_level

## Rating

- A：需求、资源、决策路径和下一动作较明确
- B：存在明确价值，但关键条件待验证
- C：长期观察或关系储备

不得仅因“聊得投机”评为 A。
